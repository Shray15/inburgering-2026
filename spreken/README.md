# Spreken — A2

Not booked yet. Structure ready for when it's scheduled.

## Format

Short spoken responses to everyday situations/questions — the A2 spreken exam checks whether
you can produce simple, correct sentences fluently on familiar topics, not complex
storytelling.

## Practice loop

1. Pick a topic from `onderwerpen.md`.
2. Answer out loud, record yourself (voice memo), 30-60 sec.
3. Listen back — note grammar/pronunciation slips.
4. Recurring mistake → GitHub Issue, label `skill:spreken`.
