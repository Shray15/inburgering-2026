# Schrijven — A2

## Format

The A2 schrijven exam is a set of short functional writing tasks: you're given a situation
(often a form to fill in or a short message to write) and respond in a few sentences. It is
**not** essay writing — it's testing whether you can produce correct, functional short texts
under time pressure.

Typical task types (see `voorbeelden/`):

- een afspraak afzeggen of verzetten
- een klacht indienen
- iets aanvragen / om informatie vragen
- iemand uitnodigen
- informatie doorgeven (bv. aan school, huisarts, werkgever)
- een formulier invullen

## Scoring tips

- **Register**: default to formal (`u`) unless the situation is clearly informal (a friend,
  a note to a neighbour you know well).
- **Completeness**: answer every part of the prompt — graders check whether required
  information is present, not just grammar.
- **Correct greeting/closing**: matched to register — see `zinnen.md`.
- **Short and correct beats long and risky**: a simple correct sentence scores better than an
  ambitious one with errors.
- **Spelling of high-frequency words** (d/t, dubbele klinkers) gets checked — this is where
  most avoidable points are lost.

## Practice loop

1. Pick a task type from `voorbeelden/`.
2. Write a response cold, timed (~5 min), save it in `oefeningen/YYYY-MM-DD.md`.
3. Compare against the model text.
4. Any recurring mistake → open a GitHub Issue with the `mistake` template, label
   `skill:schrijven`.
