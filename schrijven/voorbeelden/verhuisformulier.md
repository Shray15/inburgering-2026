# Example: verhuisformulier (adreswijziging bij de gemeente)

**Situation**: Je verhuist en moet dit doorgeven aan de gemeente via een formulier.

**Model (filled fields)**

| Veld | Invulling |
|---|---|
| Achternaam | Bakker |
| Voornaam | Tom |
| Geboortedatum | 03-04-1990 |
| Huidig adres | Oudestraat 8, 1011 AB, Amsterdam |
| Nieuw adres | Voorbeeldstraat 45, 5678 CD, Utrecht |
| Datum van verhuizing | 01-09-2026 |
| Aantal personen dat meeverhuist | 1 |
| Telefoonnummer | 06-11223344 |
| Datum (van het formulier) | 19-08-2026 |
| Handtekening | T. Bakker |

**Why this works**: both old and new address given in full (gemeente needs both), exact move
date, all required fields filled — no blanks left for the reader to guess at.
